EventTypeFilter

interface EventTypeFilter

Match by event struct type, specified as a Move type string.

Specificity levels: "0xaddr" -> matches events whose type is defined at this address "0xaddr::module" -> matches events whose type is in this module "0xaddr::module::Name" -> matches events with this type name (any instantiation) "0xaddr::module::Name" -> matches events with this exact generic instantiation
